## Project Overview

Algorithm Explorer is a single desktop application that lets a user:
- Enter their own input
- Watch algorithms run step-by-step
- See the number of operations and exact running time
- Compare different algorithms side-by-side

All algorithms and data structures are implemented **from first principles** 

### Modules

1. **Recursion Lab**
   - Fibonacci (naive recursion, memoized, bottom-up DP)
   - Factorial (recursive & iterative)
   - Animated Tower of Hanoi

2. **Data Structures Lab**
   - Array-based Stack
   - Linear Queue & Circular Queue (with “false full” demonstration)
   - Singly Linked List & Doubly Linked List
   - Bracket balance checker using Stack

3. **Sorting Lab**
   - Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quicksort
   - Step-by-step visualisation + Auto-play
   - “Compare All” table
   - Operation counts and timing

4. **Time Complexity Analysis**
   - Experimental measurements for different input sizes and patterns
   - Tables and discussion relating results to Big-O
